TURBO FOR CLAUDE CODE  (v1.0.0)

Windows:
  1. Unzip this folder anywhere.
  2. Right-click inside the folder > Open in Terminal (PowerShell), then run:   .\install.ps1
     (if scripts are blocked:  powershell -ExecutionPolicy Bypass -File .\install.ps1 )
  3. Start Claude Code in any project and type:  /turbo:help

macOS / Linux:   ./install.sh

Needs Node.js 18+ and Claude Code. Nothing else. Full details in README.md.
Uninstall:  node "%USERPROFILE%\.claude\turbo-kit\install.js" --uninstall
